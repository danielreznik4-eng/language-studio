# Lesson Studio + English Coach

- `/` - Lesson Studio: the teacher makes lessons and gets a room code; students join with the link (video call, chat, live slides and answers).
- `/english` - English Coach: step-by-step English / Russian lessons.

Runs with plain Node.js (no packages): `node server.js`. On Render it uses the PORT it is given.
Saved lessons on the free Render plan are deleted when the server restarts - use "Download file" to keep a copy.
